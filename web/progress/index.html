RULES OF THE WORKBENCH

Keep the meaning visible.

  • Opening a saved record never fetches data or reruns the analyst.
  • Financial choices belong in policy and saved assumptions. Arithmetic belongs in the formula registry.
  • Shared code takes explicit company inputs. Issuer assumptions belong in company examples or private inputs.
  • Public Git holds code and safe project status. Exact research and credentials remain private.
  • Task completion measures delivery, not investment confidence.

First saved-review view. Financial mapping, broader company validation and later workflow controls still need their own acceptance evidence. A readable result does not establish accounting correctness or predictive accuracy.
